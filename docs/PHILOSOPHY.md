# Philosophy

## Mission

Create an expandable ocean canvas where players can build continents manually while retaining as much vanilla Minecraft generation and future compatibility as technically possible.

## Non-negotiable rules

1. **No save lock-in.** A world must load and remain playable when Ocean Canvas is absent.
2. **Generated chunks are ordinary vanilla chunks.** The mod must not require custom blocks, items, entities, dimensions, biomes, or persistent registry entries.
3. **Existing chunks are immutable by default.** Configuration changes affect only future chunk generation.
4. **No automatic deletion.** Pruning is performed by the owner after a backup using external tools.
5. **Vanilla first.** Preserve caves, ores, aquifers, underground biomes, structures, and update content wherever possible.
6. **Visible behavior.** Radius, center, transition, coverage, and update risk must be inspectable.
