# Ocean Canvas

> Ocean Canvas exists so players can spend years building the world they imagine—not years fighting world generation.

Ocean Canvas is a Fabric mod under active development for creating a configurable, expandable ocean build region while preserving vanilla Minecraft world data and avoiding save lock-in.

## Status

The repository is being bootstrapped. The first milestone is a compiling Minecraft 26.2 project with configuration, commands, Mod Menu support, documentation, and automated builds.

Do not use development builds for a permanent world until a release is explicitly marked safe for testing.
